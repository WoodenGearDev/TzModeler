# TzModeler

TzModeler 0.5.0-beta — Wooden Gear Studio
РУССКИЙ / УКРАЇНСЬКА / ENGLISH

================ РУССКИЙ ================

Бесплатная самостоятельная программа для просмотра моделей Trainz.
Это бета-версия: возможны ошибки и незавершённые возможности.

ЗАПУСК
1. Полностью распакуйте ZIP в отдельную папку.
2. Запустите TzModeler.exe и ознакомьтесь с лицензией.
3. Откройте файл модели или папку кнопками в программе либо перетащите их в окно.
Установка, Blender, Python и отдельная установка .NET не нужны.
Сборка предназначена для 64-разрядной Windows (x64); просмотр 3D использует DirectX.
Согласие с лицензией запоминается для текущей версии; после обновления запрашивается снова.

ЧТО МОЖНО ПРОВЕРИТЬ
• Открытие .im, .trainzmesh и .lm/.lm.txt, выбор уровней детализации (LOD).
• Текстуры, материалы, кости и точки привязки; подсветка и координаты точек.
• Четыре темы, три языка, угол обзора и режимы сглаживания.
Правой кнопкой мыши вращайте камеру, зажатым колёсиком или Shift + правой кнопкой
сдвигайте её, колёсиком приближайте/отдаляйте. C — центрирование на выбранном,
а без выбора — на видимых объектах. Полная памятка: «Настройки → О программе».

ОГРАНИЧЕНИЯ
Редактирование и сохранение моделей/точек, обратный перевод FBX → .im и кнопка
экспорта FBX в окне пока не реализованы. Формат .pm пока не поддерживается.
Храните собственные резервные копии важных файлов. Опыты с изменением текстур
выполняйте на копии папки модели.

ПРЕДУПРЕЖДЕНИЯ WINDOWS
У этой сборки нет цифровой подписи издателя. Это не означает отсутствие лицензии:
условия использования приведены в LICENSE.txt и в самой программе.
Windows SmartScreen может показать предупреждение о неизвестном приложении.
Предупреждение само по себе не доказывает ни наличие угрозы, ни безопасность файла.
Скачивайте программу из официального источника. Если антивирус сообщает конкретную
угрозу, остановитесь и сообщите автору. Не отключайте антивирус или защиту Windows.

ОБНОВЛЕНИЯ И ОБРАТНАЯ СВЯЗЬ
При запуске программа проверяет GitHub в фоне; без интернета продолжает работать.
Обновления не устанавливаются автоматически: кнопка скачивания открывает страницу выпуска.
Описание изменений этой версии — CHANGELOG.txt и «Настройки → Что нового».
Если нашли ошибку, укажите версию, Windows, видеокарту, действия и ожидаемый результат;
по возможности приложите снимок и пример модели, которым имеете право поделиться.

================ ENGLISH ================

A free standalone viewer for Trainz models.
This is a beta release: bugs and unfinished features are possible.

GETTING STARTED
1. Extract the entire ZIP into a separate folder.
2. Run TzModeler.exe and read the license agreement.
3. Open a model file or folder using the buttons, or drag it into the window.
No installation, Blender, Python or separate .NET installation is required.
This build is for 64-bit Windows (x64); the 3D view uses DirectX.
License acceptance is remembered for the current version and requested again after an update.

WHAT TO TRY
• Open .im, .trainzmesh and .lm/.lm.txt files and switch levels of detail (LOD).
• View textures, materials, bones and attachment points; highlight points and view coordinates.
• Try four themes, three languages, field of view and antialiasing settings.
Right mouse button: rotate. Hold the mouse wheel or Shift + right mouse button: pan.
Mouse wheel: zoom. C: centre on the selection, or on visible objects if nothing is selected.
The full controls guide is in Settings → About.

LIMITATIONS
Editing and saving models/points, FBX → .im conversion and an FBX export button
in the window are not implemented yet. The .pm format is not supported yet.
Keep your own backup copies of important files. Test texture edits on a copy
of the model folder.

WINDOWS WARNINGS
This build does not have a publisher's digital signature. It does have a license:
see LICENSE.txt and the license agreement inside the program.
Windows SmartScreen may warn that the app is unrecognised.
The warning alone proves neither that the file is malicious nor that it is safe.
Download from the official source. If antivirus software reports a specific threat,
stop and contact the author. Do not disable antivirus software or Windows protection.

UPDATES AND FEEDBACK
The program checks GitHub in the background at startup and keeps working offline.
Updates are not installed automatically: the download button opens the release page.
See CHANGELOG.txt or Settings → What's new for the changes in this version.
When reporting a bug, include the app version, Windows, graphics card, steps and expected result.
If possible, attach a screenshot and a sample model that you have permission to share.
