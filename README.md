# TzModeler

**Wooden Gear Studio** · free viewer for Trainz models · бесплатный просмотрщик моделей Trainz · безкоштовний переглядач моделей Trainz

**Current version / Текущая версия / Поточна версія: 0.6.1-beta** → [Releases](https://github.com/WoodenGearDev/TzModeler/releases)

Windows x64. Unzip and run — no installation, Blender, Python or .NET needed.

---

## English

**What it does**
- Opens `.im`, `.trainzmesh` and `.lm` / `.lm.txt` files, a single file or a whole folder (also by drag and drop).
- Switches levels of detail (LOD).
- Shows textures, materials, bones and attachment points, with highlighting and point coordinates.
- Texture viewer with RGB / R / G / B / A channels; reading of binary `.texture` files (DXT1, DXT5).
- Trainz content folder: asset search by KUID, dependencies window, read-only `config.txt` viewer, assembling composite models from the mesh-table. Works only with assets in the Trainz `editing` folder; installed and packaged content is not read.
- Rendering: lighting, normal maps, PBR, SSAO, shadows, sky background, anisotropic filtering, antialiasing, wireframe, grid, field of view.
- Four themes, three languages (Russian, Ukrainian, English).

*Beta release: bugs are possible. Windows SmartScreen may warn about an unsigned app. License: see LICENSE.txt.*

## Русский

**Что умеет программа**
- Открывает `.im`, `.trainzmesh` и `.lm` / `.lm.txt`: один файл или папку целиком, в том числе перетаскиванием.
- Переключает уровни детализации (LOD).
- Показывает текстуры, материалы, кости и точки привязки, с подсветкой и координатами точек.
- Просмотр текстур по каналам RGB / R / G / B / A; чтение двоичных `.texture` (DXT1, DXT5).
- Папка контента Trainz: поиск ассетов по KUID, окно зависимостей, просмотр `config.txt` только для чтения, сборка составных моделей по mesh-table. Работает только с ассетами из папки `editing`; установленный и упакованный контент не читается.
- Отображение: освещение, рельеф, PBR, SSAO, тени, фон неба, анизотропная фильтрация, сглаживание, каркас, сетка, угол обзора.
- Четыре темы, три языка (русский, украинский, английский).

*Бета-версия: возможны ошибки. Windows SmartScreen может предупредить о неподписанной программе. Лицензия — в LICENSE.txt.*

## Українська

**Що вміє програма**
- Відкриває `.im`, `.trainzmesh` і `.lm` / `.lm.txt`: один файл або теку цілком, зокрема перетягуванням.
- Перемикає рівні деталізації (LOD).
- Показує текстури, матеріали, кістки й точки прив'язки, з підсвічуванням і координатами точок.
- Перегляд текстур за каналами RGB / R / G / B / A; читання двійкових `.texture` (DXT1, DXT5).
- Тека контенту Trainz: пошук асетів за KUID, вікно залежностей, перегляд `config.txt` лише для читання, збирання складених моделей за mesh-table. Працює лише з асетами з теки `editing`; встановлений і запакований контент не читається.
- Відображення: освітлення, рельєф, PBR, SSAO, тіні, тло неба, анізотропна фільтрація, згладжування, каркас, сітка, кут огляду.
- Чотири теми, три мови (російська, українська, англійська).

*Бета-версія: можливі помилки. Windows SmartScreen може попередити про непідписану програму. Ліцензія — у LICENSE.txt.*
